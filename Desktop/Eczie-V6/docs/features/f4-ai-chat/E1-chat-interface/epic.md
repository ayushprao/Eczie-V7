# E1: Chat Interface

## Feature Reference
- Feature: F4 - AI Chat
- PRD Section: 2.5.1 - 2.5.2, 2.5.9 - 2.5.11

## Epic Overview

Implements the chat screen UI including header, mode toggle between Skin Coach and Emotional Support, message list display, quick actions, disclaimer, and input area.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Chat Header & Mode Toggle | Navigation, title, mode selection |
| S2 | Message List | Conversation display with timestamps |
| S3 | Input Area | Text input, attachment, send button |
| S4 | Quick Actions & Disclaimer | Action pills and legal disclaimer |

## Acceptance Criteria (Epic-Level)

- [ ] User can navigate to/from chat
- [ ] User can switch between modes
- [ ] User can view message history
- [ ] User can send messages
- [ ] Disclaimer is always visible

## UX Requirements

- Messages scroll with newest at bottom
- Input area fixed at bottom
- Disclaimer visible above input
