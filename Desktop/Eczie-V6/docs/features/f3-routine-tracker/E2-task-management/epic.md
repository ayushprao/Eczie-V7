# E2: Task Management

## Feature Reference
- Feature: F3 - Routine Tracker
- PRD Section: 2.4.1 - 2.4.8

## Epic Overview

Implements the Add Routine screen for creating new routine tasks with category, name, icon, time, frequency, and notes.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Add Task Form | Complete form for new task creation |
| S2 | FAB Navigation | Floating action button to access form |

## Acceptance Criteria (Epic-Level)

- [ ] User can tap FAB to open Add Routine screen
- [ ] User can fill out task details
- [ ] User can save new task
- [ ] New task appears in Routine Tracker list

## UX Requirements

- FAB is always visible on Routine Tracker
- Form validates required fields
- Save navigates back with new task visible
