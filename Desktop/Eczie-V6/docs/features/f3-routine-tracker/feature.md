# F3: Routine Tracker

## Overview

The Routine Tracker enables users to manage and track daily skincare, medication, and lifestyle tasks. It provides visibility into adherence and supports habit formation.

## PRD Reference

- Section 2.3: ROUTINE TRACKER SCREEN
- Section 2.4: ADD ROUTINE SCREEN

## User Outcomes

- View daily routine tasks by category
- Mark tasks as complete/incomplete
- Track weekly progress
- Add new routine tasks

## Epics

| ID | Epic | Description |
|----|------|-------------|
| E1 | Routine Display | Header, calendar, progress, task list |
| E2 | Task Management | Add new routine tasks |

## Dependencies

- Navigation from Home (F1)
- Task data model

## Out of Scope

- Recurring task scheduling beyond daily/custom
- Task reminders/notifications (separate feature)
