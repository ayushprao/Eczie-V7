# E1: Routine Display

## Feature Reference
- Feature: F3 - Routine Tracker
- PRD Section: 2.3.1 - 2.3.6

## Epic Overview

Implements the routine tracker screen with header, weekly calendar strip, progress summary, and categorized task list with completion toggles.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Tracker Header | Back navigation, title, menu |
| S2 | Weekly Calendar | 7-day strip with completion states |
| S3 | Progress Summary | Task count and progress bar |
| S4 | Task List | Categorized tasks with checkboxes |

## Acceptance Criteria (Epic-Level)

- [ ] User can navigate back
- [ ] User can view weekly calendar
- [ ] User can see progress percentage
- [ ] User can toggle task completion
- [ ] User can access FAB to add tasks

## UX Requirements

- Progress visible above the fold
- Task list scrollable
- FAB always visible
