# S1: Tracker Header

## References
- Feature: F3 - Routine Tracker
- Epic: E1 - Routine Display
- PRD Section: 2.3.1

## User Story

As a user, I want a clear header with navigation so that I can return to previous screens and access options.

## Acceptance Criteria

- [ ] Display back button (left chevron) that navigates back
- [ ] Display title "Today's Routine"
- [ ] Display menu button (three dots)
- [ ] Tapping menu opens options menu

## UX Requirements

- Header fixed at top
- Menu options: Edit Tasks, Delete Tasks (design assumption)
- Menu appears as bottom sheet or dropdown

## Non-Functional Requirements

- Accessible: all buttons properly labeled

## Dependencies

- Navigation system

Check `story-images/` for header layout. Menu options are a design gap - implement basic Edit/Delete.
