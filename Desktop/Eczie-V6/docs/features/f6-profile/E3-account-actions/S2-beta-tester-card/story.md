# S2: Beta Tester Card

## References
- Feature: F6 - Profile
- Epic: E3 - Account Actions
- PRD Section: 2.8.7

## User Story

As a beta tester, I want acknowledgment of my early participation so that I feel valued.

## Acceptance Criteria

- [ ] Display card with star badge icon
- [ ] Display title "You're an Early Beta Tester!"
- [ ] Display thank you message acknowledging contribution
- [ ] Card only visible for users flagged as beta testers

## UX Requirements

- Card is visually distinct (special styling)
- Warm, appreciative tone
- Non-interactive (display only)

## Non-Functional Requirements

- Beta tester flag from user profile
- Hide card for non-beta users
- Accessible: card content readable

## Dependencies

- User profile with beta tester flag
