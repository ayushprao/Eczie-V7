# E3: Account Actions

## Feature Reference
- Feature: F6 - Profile
- PRD Section: 2.8.6 - 2.8.8

## Epic Overview

Implements support/about section, beta tester acknowledgment, and account actions including sign out and account deletion.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Support Menu | FAQ, privacy, feedback, version info |
| S2 | Beta Tester Card | Acknowledgment card for early users |
| S3 | Sign Out & Delete | Account action buttons with confirmations |

## Acceptance Criteria (Epic-Level)

- [ ] User can access support resources
- [ ] User sees beta tester acknowledgment (if applicable)
- [ ] User can sign out with confirmation
- [ ] User can delete account with multi-step confirmation

## UX Requirements

- Support menu in list format
- Delete account is clearly destructive
- Confirmations prevent accidental actions
