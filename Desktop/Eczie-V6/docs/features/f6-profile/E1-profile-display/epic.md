# E1: Profile Display

## Feature Reference
- Feature: F6 - Profile
- PRD Section: 2.8.1 - 2.8.4

## Epic Overview

Implements the profile screen header, user profile card with subscription status, stats grid, and symptom calendar.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Profile Header | Navigation, title, settings button |
| S2 | User Profile Card | Avatar, name, email, subscription |
| S3 | Stats Grid | Total logs, best streak, avg severity, backup |
| S4 | Profile Calendar | Symptom calendar (reused component) |

## Acceptance Criteria (Epic-Level)

- [ ] User can view their profile information
- [ ] User can see key stats
- [ ] User can view symptom calendar
- [ ] User can access settings

## UX Requirements

- Profile card prominent at top
- Stats in grid layout
- Calendar below stats
