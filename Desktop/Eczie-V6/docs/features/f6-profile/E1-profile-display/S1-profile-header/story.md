# S1: Profile Header

## References
- Feature: F6 - Profile
- Epic: E1 - Profile Display
- PRD Section: 2.8.1

## User Story

As a user, I want a clear header with settings access so that I can navigate and configure the app.

## Acceptance Criteria

- [ ] Display back button (left chevron) for navigation
- [ ] Display title "Profile"
- [ ] Display settings button (gear icon)
- [ ] Tapping settings navigates to Settings screen

## UX Requirements

- Header fixed at top
- Settings button clearly visible

## Non-Functional Requirements

- Accessible: buttons properly labeled

## Dependencies

- Navigation system
- Settings screen (design gap - not in PRD)

## Design Notes

Check `story-images/` for header layout. Settings screen is a design gap - implement placeholder or basic settings.
