# F6: Profile

## Overview

The Profile feature provides user account management, data history access, export capabilities, support resources, and account actions including sign out and deletion.

## PRD Reference

- Section 2.8: PROFILE SCREEN

## User Outcomes

- View profile information and stats
- Access symptom calendar
- Manage log history and data export
- Access support and legal information
- Sign out or delete account

## Epics

| ID | Epic | Description |
|----|------|-------------|
| E1 | Profile Display | Header, user card, stats, calendar |
| E2 | Data Management | History, export, delete entries |
| E3 | Account Actions | Sign out, delete account, support |

## Dependencies

- User authentication
- Log data
- Bottom navigation

## Out of Scope

- Profile photo editing
- Password change (handled by auth provider)
- Subscription management UI
