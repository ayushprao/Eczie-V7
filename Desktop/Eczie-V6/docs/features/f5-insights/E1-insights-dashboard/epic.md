# E1: Insights Dashboard

## Feature Reference
- Feature: F5 - Insights
- PRD Section: 2.6.1 - 2.6.8

## Epic Overview

Implements the main Insights screen with AI summary, severity metrics, symptom trends, flare chart, calendar visualization, and recent log entries.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Insights Header | Navigation and title |
| S2 | AI Summary Card | Week at a glance with report link |
| S3 | Severity Metrics | Average severity and symptom trends |
| S4 | Flare Chart | 7-day severity line graph |
| S5 | Symptom Calendar | Monthly calendar with severity indicators |
| S6 | Recent Logs | List of recent log entries |

## Acceptance Criteria (Epic-Level)

- [ ] User can view AI-generated summary
- [ ] User can see average severity with trend
- [ ] User can view severity chart
- [ ] User can navigate calendar months
- [ ] User can tap logs to view details

## UX Requirements

- Summary card above the fold
- Scrollable content below
- Chart is interactive (optional: tap for details)
