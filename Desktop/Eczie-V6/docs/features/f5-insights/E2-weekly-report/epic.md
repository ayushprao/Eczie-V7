# E2: Weekly Report

## Feature Reference
- Feature: F5 - Insights
- PRD Section: 2.7.1 - 2.7.6

## Epic Overview

Implements the detailed Weekly Insights Report screen with AI coach summary, routine adherence, progress metrics, detected triggers, and sharing capabilities.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Report Header | Navigation, share, title, date range |
| S2 | AI Coach Summary | Detailed AI analysis with topic tags |
| S3 | Adherence & Progress | Routine adherence and progress metrics |
| S4 | Detected Triggers | Trigger list with correlation percentages |
| S5 | Share Actions | PDF export and send to doctor |

## Acceptance Criteria (Epic-Level)

- [ ] User can view detailed AI summary
- [ ] User can see routine adherence breakdown
- [ ] User can see detected triggers with confidence
- [ ] User can share report as PDF
- [ ] User can send report to doctor

## UX Requirements

- Long-form content, scrollable
- Share actions at bottom
- Trigger risk levels color-coded
