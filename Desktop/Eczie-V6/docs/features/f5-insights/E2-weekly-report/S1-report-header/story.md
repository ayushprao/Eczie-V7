# S1: Report Header

## References
- Feature: F5 - Insights
- Epic: E2 - Weekly Report
- PRD Section: 2.7.1

## User Story

As a user, I want a clear header with date range and share option so that I know which week I'm viewing and can easily share.

## Acceptance Criteria

- [ ] Display back button (left chevron) for navigation
- [ ] Display share button (share icon)
- [ ] Display title "Weekly Insights Report"
- [ ] Display date range (e.g., "June 17-23, 2025")
- [ ] Tapping share opens system share sheet

## UX Requirements

- Header fixed at top
- Date range clearly visible below title
- Share button prominent

## Non-Functional Requirements

- Share includes report summary text
- Accessible: buttons properly labeled

## Dependencies

- Navigation system
- Share functionality
