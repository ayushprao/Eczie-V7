# F5: Insights

## Overview

The Insights feature provides users with trend analysis, visualizations, and AI-generated reports to help them understand patterns in their eczema symptoms and identify triggers.

## PRD Reference

- Section 2.6: INSIGHTS SCREEN
- Section 2.7: WEEKLY INSIGHTS REPORT SCREEN

## User Outcomes

- View average symptom severity and trends
- Visualize flare patterns over time
- Review symptom calendar
- Access detailed weekly AI reports
- Understand detected triggers with correlation data
- Share reports with healthcare providers

## Epics

| ID | Epic | Description |
|----|------|-------------|
| E1 | Insights Dashboard | Summary, trends, charts, calendar, recent logs |
| E2 | Weekly Report | Detailed AI analysis with sharing |

## Dependencies

- User log data
- AI analysis backend
- Bottom navigation

## Out of Scope

- Custom date range selection
- Comparison between time periods
- Export of raw data (handled in Profile)
