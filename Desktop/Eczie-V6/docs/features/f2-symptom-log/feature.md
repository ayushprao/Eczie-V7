# F2: Symptom Log

## Overview

The Symptom Log is the primary data entry screen for tracking daily symptoms, lifestyle factors, triggers, and photos. It enables users to build a comprehensive record for pattern detection.

## PRD Reference

- Section 2.2: SYMPTOM LOG SCREEN

## User Outcomes

- Log symptom severity (itchiness, redness, dryness)
- Record additional symptoms
- Track lifestyle factors (sleep, stress)
- Identify potential triggers
- Attach photos of affected areas
- Add contextual notes

## Epics

| ID | Epic | Description |
|----|------|-------------|
| E1 | Symptom Entry | Header, sliders, severity score |
| E2 | Factors & Triggers | Additional symptoms, lifestyle, triggers |
| E3 | Media & Notes | Photo upload and notes |
| E4 | Save Flow | Save action with confirmation |

## Dependencies

- Navigation from Home (F1)
- Daily log data model
- Photo storage

## Out of Scope

- Historical log editing (view-only for past logs)
- Bulk import of logs
