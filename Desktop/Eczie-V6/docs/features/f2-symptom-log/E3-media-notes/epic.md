# E3: Media & Notes

## Feature Reference
- Feature: F2 - Symptom Log
- PRD Section: 2.2.7 - 2.2.8

## Epic Overview

Implements photo upload functionality for documenting affected areas and free-text notes for additional context.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Photo Upload | Add, view, and remove photos |
| S2 | Additional Notes | Free-text notes input |

## Acceptance Criteria (Epic-Level)

- [ ] User can add photos from camera or gallery
- [ ] User can view uploaded photo thumbnails
- [ ] User can remove photos before saving
- [ ] User can add free-text notes

## UX Requirements

- Photos section uses horizontal scroll
- Notes field is multi-line with placeholder
- Both sections are optional
