# E2: Factors & Triggers

## Feature Reference
- Feature: F2 - Symptom Log
- PRD Section: 2.2.4 - 2.2.6

## Epic Overview

Implements the secondary data entry sections for additional symptoms, lifestyle factors (sleep, stress), and potential triggers (environment, food, personal).

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Additional Symptoms | Multi-select chips for secondary symptoms |
| S2 | Lifestyle Factors | Sleep duration and stress level selection |
| S3 | Trigger Selection | Environment, food, personal trigger chips |

## Acceptance Criteria (Epic-Level)

- [ ] User can select multiple additional symptoms
- [ ] User can add custom symptoms
- [ ] User can select sleep duration
- [ ] User can select stress level
- [ ] User can select multiple triggers across categories
- [ ] User can add custom triggers

## UX Requirements

- All sections use chip-based selection
- Sections are clearly labeled with headers
- Optional nature indicated where applicable
