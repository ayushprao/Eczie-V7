# E2: Progress & Streaks

## Feature Reference
- Feature: F1 - Home Dashboard
- PRD Section: 2.1.5 - 2.1.6

## Epic Overview

Implements progress metrics display and streak visualization to reinforce consistent logging behavior and show users their skin health journey.

## Stories

| ID | Story | Description |
|----|-------|-------------|
| S1 | Progress Metrics | Flare-free days, moderate days, flares this month |
| S2 | Streak Card | Current streak with weekly day indicators |

## Acceptance Criteria (Epic-Level)

- [ ] User sees three progress metrics
- [ ] User sees current streak count
- [ ] User sees weekly completion indicators
- [ ] Metrics update after new log entries

## UX Requirements

- Progress section below action cards
- Streak card provides motivational reinforcement
- No guilt messaging for broken streaks
