# Story: Action Cards

**Epic:** Home Dashboard
**PRD Ref:** §2.1.4 Action Cards

## Summary

Two tappable cards that launch the primary logging flows: "Complete Entry" (→ Symptom Log) and "Track Routine" (→ Routine Tracker).

## Functional Requirements

- Card 1: "Complete Entry" / "Symptoms & Triggers" with clipboard icon → navigates to Symptom Log screen
- Card 2: "Track Routine" / "Skincare & Medications" with checklist icon → navigates to Routine Tracker screen
- Cards are always visible; no conditional logic

## Non-Functional Requirements

- Tap feedback (press state / ripple)
- Cards render statically — no data fetch required
